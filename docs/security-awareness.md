# Security Awareness

## 10 Password Security Rules
1. Use unique passwords for different accounts — reuse means one compromised credential can affect multiple services.
2. Prefer longer passwords or randomly selected passphrases — length can make guessing harder when combined with unpredictability.
3. Avoid predictable personal information — names, dates and organization details can be guessable.
4. Avoid common passwords — common values are high-priority guesses.
5. Avoid password reuse — treat important accounts independently.
6. Use a password manager — it can generate and store unique credentials.
7. Enable MFA — it adds another factor beyond the password.
8. Never share passwords — legitimate services should not need your plaintext password through casual messages.
9. Be cautious of phishing — a strong password can still be disclosed to a fake login page.
10. Change passwords when compromise is suspected or confirmed — respond to evidence of exposure rather than relying on arbitrary periodic changes.

## Real-World Login Security
Password security is one part of authentication. A mature system also needs MFA, rate limiting, secure password hashing, abuse protection, session security, phishing resistance and monitoring.
